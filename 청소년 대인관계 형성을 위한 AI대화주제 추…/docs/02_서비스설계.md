## 여정

1. 이 서비스로 무엇을 만들 수 있는지 홈에서 확인합니다.
2. 지금 하려는 목적에 맞는 기능을 고릅니다.
3. 프롬프트를 쓰거나 필요한 자료를 올립니다.
4. 결과물이 만들어지는 동안 진행 상태를 지켜봅니다.
5. 만들어진 결과물을 확인합니다.

## MVP 필수

- 이용자가 프롬프트나 자료를 입력하면 AI가 결과물을 만들어 보여줍니다.
- 만들어진 결과물을 화면에서 바로 확인할 수 있게 합니다.
- 이전에 만든 결과물을 목록으로 모아 다시 볼 수 있게 합니다.

## UX·디자인 방향

**선택한 방향**: Bold Funnel — 토스처럼 한 문장씩 — 흰 화면에 큰 문장 하나, 토스처럼 심플한 한국형 퍼널 느낌

**어울리는 서비스**: 금융·생활 서비스, 예약·신청형 서비스, 회원가입·온보딩 퍼널

**디자인 핵심**

- 흰 배경(#ffffff)에 상하 여백 24px 이상을 두고, 화면마다 20px 이상 큰 문장 하나에만 집중하게 합니다
- 포인트 색은 파랑(#3182f6) 하나만 써서 버튼·강조 요소에만 쓰고, 나머지는 무채색(#191f28/#f2f4f6)으로 절제합니다
- 버튼은 높이 52px 이상, 모서리 16px로 크고 둥글게 그려 다음 동작을 망설임 없이 누르게 합니다
- 새 화면 전환 대신 아래에서 올라오는 바텀시트(300ms ease-out)로 다음 단계를 잇는 경우가 많습니다
- 이 위저드도 한 화면에 한 질문만 묻는 같은 문법을 쓰고 있습니다

**형태 스펙**: 주조색 `#ffffff`, 면 `#f2f4f6`, 포인트 `#3182f6`, 글자 `#191f28` / 모서리 16px / 그림자 soft(은은한 기본 그림자) / 레이아웃 문법 landing(상단 내비 + 히어로 + 3열 특징) / 글자꼴 sans(고딕 계열) / 라이트 기조
